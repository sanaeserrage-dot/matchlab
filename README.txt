# MatchLab — iPhone PWA

## تشغيل سريع
1. فك ضغط `MatchLab-iPhone.zip`.
2. ارفع محتويات المجلد إلى استضافة HTTPS ثابتة مثل GitHub Pages أو Netlify (لا يحتاج Backend).
3. افتح رابط `index.html`/الموقع في Safari على iPhone.
4. اضغط مشاركة Share ثم Add to Home Screen.

## البيانات
- يستخدم التطبيق نقاط ESPN العامة غير الرسمية: scoreboard و team schedule.
- لا يحتاج API key أو تسجيل دخول.
- التغطية تختلف حسب الدوري والموسم؛ "جميع المسابقات" تعني جميع المسابقات الموجودة في القائمة داخل التطبيق، وليس كل دوري في العالم.
- يمكن تعديل مصفوفة `LEAGUES` في `index.html` لإضافة رموز مسابقات أخرى يدعمها ESPN.

## جلب المباريات\n- النسخة المحدّثة تجلب نافذة 7 أيام ابتداءً من التاريخ المختار (مع يوم سابق واحد) حتى لا تظهر الشاشة فارغة في يوم قليل المباريات.\n- كل مباراة تعرض تاريخها وتوقيتها المحليين.\n\n## التحليل
- آخر 8 نتائج مكتملة متاحة لكل فريق.
- متوسط التسجيل والاستقبال + تعديل أرضي بسيط.
- تقديرات Poisson للفوز/التعادل/الخسارة وOver 2.5 وBTTS والنتيجة الأرجح.
- لا يدّعي وجود xG أو إصابات أو تشكيلة إذا لم يجلبها.
- التوقعات احتمالية وليست ضماناً أو توصية مراهنة.

## ملاحظات تقنية
- واجهة ثابتة، وتستدعي ESPN مباشرة من المتصفح.
- API ESPN غير موثق رسمياً ويمكن أن يتغير أو يتوقف، ولا توجد SLA.
- إذا لم تعمل البيانات من داخل استضافة معينة، جرّب فتح الموقع على شبكة أخرى؛ لا تستخدم Proxy مجهول.
